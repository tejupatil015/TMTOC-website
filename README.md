# Madhavi Bhide – Homemade Papad & Pickles 👻

A creative web development project created for a Web Development Competition
based on a Wild Card Theme inspired by Taarak Mehta Ka Ooltah Chashmah.

## ✨ Features

- Horror & Ghost inspired UI
- Smooth CSS animations
- Ghost sound effects
- Interactive elements
- Custom papad & pickle visuals
- Animated product sections
- Creative storytelling
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 Project Concept

We transformed a traditional homemade papad and pickle business concept
into an interactive horror-themed web experience using animation,
sound, custom visuals and creative UI design.

## 👥 Competition Project

Created as part of a Web Development Competition – Wild Card Theme.
